
# Student Grade Calculator

## About the Project
This is my first Python project.
It calculates a student's average marks
and displays their grade.

## Features
- Takes student name as input
- Accepts three subject marks
- Calculates average marks
- Displays the final grade

## Technology Used
- Python

## How to Run
1. Install Python.
2. Open the terminal.
3. Run: python main.py
